# MindGraph-OSS v0.1.0-alpha.1 (draft release notes)

**Status: draft, not released.** No tag has been pushed and nothing has been
published. Release is blocked until the items marked as blockers in the
[release checklist](RELEASE_CHECKLIST.md) are resolved, including legal
approval of the licensing.

MindGraph-OSS turns structured data into an explorable knowledge graph for
humans and AI agents. This first public alpha runs locally with Docker
Compose and is meant for evaluation and feedback.

## Highlights

- **From files to a graph without AI**: upload CSV or JSON, review the
  inferred schema, define an ontology and mappings, and ingest with
  idempotent, deterministic jobs.
- **Optional AI Graph Builder**: a model proposes the ontology and mappings
  across several files; Rust validates everything and nothing is written
  until you approve it.
- **Graph Explorer**: search, expand neighbourhoods and find shortest paths
  on a WebGL canvas.
- **Ask MindGraph**: questions answered from retrieved graph evidence with
  checked citations.
- **Entity resolution**: rule-based duplicate candidates, side by side
  review, logical identities without merging data.
- **MCP server**: read-only graph tools for Claude Code, Codex, Cursor and
  other MCP clients.
- **One-command demos**: `make demo-fraud`, `make demo-cyber`,
  `make demo-knowledge` load synthetic scenarios through the public API and
  verify them.

## Get started

```bash
git clone https://github.com/mindwalker-ai/MindGraph-Open
cd MindGraph-Open
docker compose up -d --build
make demo-fraud
```

Open http://localhost:3000. See [Getting started](../getting-started/README.md).

## Before you use it

- **No authentication.** Keep it on your machine; see
  [SECURITY.md](../../SECURITY.md).
- Read the [known limitations](KNOWN_LIMITATIONS.md).
- AI features are off until you configure a provider; when on, they send
  data to that provider (described in the AI guides).

## What changed in the launch-hardening milestone (M10)

- Three demo scenarios with a verified, idempotent loader and a Demos page.
- Readiness that covers HugeGraph; fixed HugeGraph heap; a fix for a
  HugeGraph memory exhaustion in path search; a fix for the Path Finder
  reloading the page.
- Placeholder UI removed; honest counts and navigation.
- Full-stack smoke test, Playwright browser journeys against the real stack,
  OpenAPI check, dependency audit and MCP release-binary tests in CI.
- Security review, license and dependency audits, benchmarks, backup and
  restore guide, governance files and a new README.

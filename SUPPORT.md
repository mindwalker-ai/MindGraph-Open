# Getting help

MindGraph-OSS is an alpha maintained on GitHub. There is no paid support,
chat channel or mailing list for it yet.

- **How do I …?** Start with the [getting started guide](docs/getting-started/README.md),
  the [tutorials](docs/tutorials/README.md) and the
  [known limitations](docs/release/KNOWN_LIMITATIONS.md).
- **Something is broken:** check the
  [troubleshooting section](docs/getting-started/README.md#troubleshooting),
  then open an issue with the bug template on
  [GitHub](https://github.com/mindwalker-ai/MindGraph-Open/issues).
- **An idea or a missing feature:** open a feature request on GitHub.
- **A security problem:** follow [SECURITY.md](SECURITY.md); do not open a
  public issue.

When you open an issue, include the version or commit, how you run
MindGraph (Docker, Podman or native), what you did and what happened. Never
paste API keys, `.env` contents or real personal data.

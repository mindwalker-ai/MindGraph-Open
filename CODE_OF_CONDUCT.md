# Code of Conduct

MindGraph-OSS adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to the repository, its issues, pull
requests and discussions, and to anyone representing the project.

In short: be respectful and constructive, assume good intent, accept
feedback gracefully, and do not harass, insult or exclude anyone. Sexualised
language or imagery, personal or political attacks, publishing someone's
private information and other conduct that would be inappropriate in a
professional setting are not acceptable.

## Reporting

The maintainers of the
[mindwalker-ai/MindGraph-Open](https://github.com/mindwalker-ai/MindGraph-Open)
repository enforce this code of conduct.

A dedicated private reporting address has not been published yet. Until it
is:

- for conduct in issues or pull requests, use GitHub's **Report content**
  option on the comment, which reaches GitHub and the repository maintainers;
- to reach the maintainers privately, use GitHub's private vulnerability
  reporting form described in [SECURITY.md](SECURITY.md) and say that the
  report concerns conduct, not a vulnerability.

Reports are handled confidentially. Maintainers may remove, edit or reject
contributions that break this code, and may restrict participation
temporarily or permanently, following the Contributor Covenant's
enforcement guidelines.
